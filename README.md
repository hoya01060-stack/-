# 📈 주식 기법 알림 봇 (한국 + 미국)

정리한 매매 기법들(9가지 + 터틀식 돌파 규칙)을 **계산 가능한 조건식**으로 바꿔서
1. 장 마감 후 전 종목을 스캔해 **관심종목 · 매수 추천**을 뽑고
2. 장중에는 몇 분마다 **매수 타이밍 / 손절 · 익절 · 불타기 · 10일선 이탈 매도** 알림을 보내고
3. 매일 **시장 동향 브리핑**(지수, 시장 폭, 업종, 환율·금·금리, 시장 국면, 선택 시 AI 해설)을

텔레그램으로 보내 주는 프로그램입니다.

> ⚠️ 이 프로그램은 조건 검색과 알림 도구이며 수익을 보장하지 않습니다. 실제 돈을 넣기 전에 반드시 `backtest`로 기법의 과거 성과를 확인하고, 소액이나 모의투자로 먼저 운용해 보세요.

## 1. 기법 → 조건식 (내가 해석한 부분 포함)

원문 기법은 사람이 보고 판단하는 표현("크게 오른 뒤", "버티는")이 많아서 숫자 기준을 정해야 했습니다. **모든 숫자는 `config.yaml`에서 바꿀 수 있습니다.**

| # | 기법 | 구현한 조건 (기본값) | 용도 |
|---|---|---|---|
| 1-1 | 거래량 급감 (코슬라) | 120일 고점 대비 **-20% 이상** 하락 + 거래량 **5일 연속 감소** | 관심종목 |
| 1-2 | 가격 방어 (아우타니) | 20일 최저가(지지선) +2% 이내까지 내려온 날이 **3회 이상**, 지지선이 **10일 이상** 유지, 최근 5일 안에 재테스트, 테스트일 거래량이 평소의 **1.3배 이상**(매도 물량 출회), 현재가는 지지선 +8% 이내 | 관심종목 (지지선 = 손절 기준) |
| 1-3 | 거래량 폭증+횡보 (시겔) | 최근 20일 평균 거래량이 그 이전 60일 평균의 **3배 이상**인데 20일 종가 변동 **3% 미만** | 관심종목 |
| 2-1 | 폭락장 버팀목 (켈) | 지수가 60일 고점 대비 -8% 이상 빠졌으면 **폭락장 모드**: 지수 낙폭의 절반도 안 빠진 종목. 평상시: 지수 -1% 이하 하락일에 지수보다 덜 빠진 정도(초과수익) 상위 20 | 관심종목(대장주 후보) |
| 2-2 | 10일선 매매 (켈) | **매수**: 10일선 아래 → 위로 돌파. **매도**: 10일선 이탈 | 매수 타이밍 / 매도 알림 |
| 2-3 | 돌파+불타기 (헨) | 10일간 **+20% 이상 급등** → **2~3일 휴식**(고점 넘지 않고 -8% 이내 눌림) → 휴식 전 고점 **돌파 시 매수**. 이후 **+5%, +10%** 마다 불타기 알림 + 손절가를 본전으로 상향 | 매수 타이밍 / 추가매수 |
| 2-4 | 20일 신고가 돌파 / 10일 신저가 이탈 (터틀식) | **매수**: 현재가가 직전 **20일 최고가**를 넘으면. **매도**: 직전 **10일 최저가**를 깨면 **전량 매도**. 20일 최고가 3% 이내 종목(최대 60개)을 장중 감시 | 매수 타이밍(단독) / 매도 알림 |
| 3 | 사이클 바닥 (마취과 의사) | **PSR ≤ 0.5** + **적자 정확히 2년차**(3년 전은 흑자) + 같은 업종 경쟁사 **50% 이상 적자**. 목표가 = 과거 최고 EPS × 5 | 장기 후보 / 목표가 알림 |
| 4-1 | 손익비 (포페) | 총자산 ÷ 10 동일비중, **-5% 손절, +15% 익절** | 모든 매수 계획에 적용 |
| 4-3 | 계좌 2% 손실 한도 | **모든 매수에 적용.** ① 매수 수량 = min(동일비중 수량, 계좌의 2% ÷ 1주당 손절폭) ② 손절가 = max(기법 손절가, 계좌 2%를 잃는 가격) → 둘 중 먼저 닿는 가격에서 무조건 손절 알림 | 수량 계산 / 손절 |
| 4-2 | 하락장 방어 (달리오) | 지수 52주 고점 대비 -15% 이상, 또는 지수 < 200일선 & 50일선 < 200일선 → **위험회피 국면**: 금·달러 ETF 제안, 매수 알림에 경고(옵션으로 중단) | 브리핑 / 경고 |

### 매수 추천은 어떻게 나오나?
- **관심종목**(1-1, 1-2, 1-3, 2-1, 3)은 "지켜볼 종목"이고, 실제 **매수 타이밍**은 2-2(10일선 돌파)나 2-3(돌파)이 발생할 때입니다.
- 추천 = **매수 타이밍 신호** + (**돌파 기법(헨, 20일 신고가) 자체**이거나, **관심종목 기법에 걸린 종목**). 아무 종목이나 10일선을 넘었다고 추천하지 않습니다.
- 20일 신고가 돌파는 하루에도 많은 종목에서 나오기 때문에, 다른 기법과 겹치는 종목 → 거래량이 많이 터진 종목 순으로 정렬해 보여줍니다.

### 계좌 2% 규칙은 언제 작동하나?
- 기본 설정(10종목 동일비중, -5% 손절)에서는 한 종목 손실이 계좌의 **0.5%**라서 2% 규칙에 걸리지 않습니다.
- 2% 규칙은 다음 두 경우에 실제로 작동합니다.
  - **손절폭이 넓을 때**: 예) 10일 최저가가 매수가보다 30% 아래 → 수량을 줄입니다.
  - **한 종목을 많이 샀을 때**: 예) `/buy`로 계좌의 절반을 넣음 → 손절가가 -5%보다 위로 올라갑니다.
- 장중 알림도 같은 원칙으로 감시목록(시장별 최대 150종목)과 보유종목만 확인합니다.

### 기법끼리 충돌하는 부분 → 매수 모드로 구분
"+15% 익절"(포페)과 "오를 때마다 불타기"(헨), "10일선 이탈 시 매도"(켈)는 동시에 지킬 수 없습니다. 그래서 `/buy`로 매수를 등록할 때 모드를 고르게 했습니다.
- `fixed`(기본): -5% 손절 / +15% 익절
- `trend`: -5% 손절 + 10일선 이탈 매도 + 불타기 알림 (돌파 매매에 적합)
- `turtle`: 10일 최저가 이탈 시 전량 매도 (20일 신고가 돌파로 산 종목용, 익절 없음 — 10일 최저가가 올라가며 자동으로 이익을 지킴)
- `cycle`: 사이클주 목표가 도달 알림 (장기 보유 전제)
- **모든 모드 공통**: 계좌 2%를 잃는 가격에 닿으면 무조건 손절 알림

## 2. 반드시 알아야 할 한계

1. **"세력 매집"은 가설입니다.** 거래량 패턴이 매집을 *시사*할 수는 있지만 증명하지는 못합니다. 그래서 1-1~1-3은 매수 신호가 아니라 관심종목으로만 씁니다.
2. **시세 지연**: KIS API 키가 없으면 yfinance를 쓰는데, 한국 주식은 약 15~20분 지연 시세입니다. 장중 알림을 제대로 쓰려면 한국투자증권 API를 권장합니다.
3. **KIS API 코드는 실제 키로 테스트하지 못했습니다.** 개발 환경에서 증권사 서버 접속이 막혀 있었습니다. 공식 문서의 엔드포인트(`inquire-price`, `overseas-price/.../price`)대로 작성했으니, 처음 실행할 때 `python -m stockbot intraday KR`로 확인해 주세요. 실패하면 자동으로 yfinance로 넘어갑니다.
4. **사이클주 데이터의 근사치**
   - 한국 EPS = 당기순이익 ÷ *현재* 상장주식수 (과거 증자·감자, 지배주주 지분 미반영)
   - 미국은 yfinance가 최근 약 4년치만 제공하므로 "과거 전성기 EPS"를 충분히 거슬러 올라가지 못합니다.
   - 업종 분류는 KRX 업종(한국), GICS 하위산업(미국, 종목이 적으면 섹터)을 씁니다.
5. **백테스트의 생존 편향**: 현재 상장된 종목만 대상이라 상장폐지 종목이 빠져서, 성과가 실제보다 좋게 나옵니다.
6. 무료 데이터 소스(네이버, 야후, 위키백과)는 구조가 바뀌면 일시적으로 작동하지 않을 수 있습니다. 그럴 때는 `pip install -U finance-datareader yfinance`로 업데이트하세요.

## 3. 설치

```bash
git clone <이 저장소>
cd <폴더>
python3 -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp config.example.yaml config.yaml
cp .env.example .env
```

### 3-1. 텔레그램 봇 만들기 (필수, 무료)
1. 텔레그램에서 **@BotFather** → `/newbot` → 이름 입력 → **토큰**을 받아 `.env`의 `TELEGRAM_BOT_TOKEN`에 넣습니다.
2. 만든 봇에게 아무 메시지나 보냅니다.
3. 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates` 를 열고 `"chat":{"id":숫자}`의 숫자를 `TELEGRAM_CHAT_ID`에 넣습니다.
4. `python -m stockbot test-telegram` → 휴대폰으로 메시지가 오면 성공입니다.

봇은 **본인 chat_id에서 온 명령만** 처리합니다.

### 3-2. 한국투자증권 Open API (장중 실시간 시세, 권장)
한국투자증권 계좌 개설 → KIS Developers(apiportal.koreainvestment.com)에서 API 신청 → App Key와 App Secret을 `.env`에 입력합니다. 미국 실시간 시세는 별도 신청이 필요할 수 있으니 KIS 안내를 확인하세요.

### 3-3. DART API (국내 사이클주, 선택)
opendart.fss.or.kr에서 무료 인증키를 발급받아 `DART_API_KEY`에 넣습니다. 없으면 국내 사이클주 스캔만 생략됩니다.

### 3-4. Claude API (브리핑 AI 해설, 선택)
`ANTHROPIC_API_KEY`를 넣으면 브리핑 끝에 수치 기반 해설이 붙습니다. 없으면 수치 브리핑만 보냅니다. API 사용료가 발생합니다(브리핑 1회당 소액).

## 4. 실행

```bash
python -m stockbot fundamentals          # 처음 1회: 사이클주 재무데이터 (이후 매주 토요일 자동)
python -m stockbot daily KR --no-send    # 한국 스캔+브리핑을 화면으로 확인 (첫 실행은 일봉 수집에 10분 이상 걸림)
python -m stockbot daily US --no-send
python -m stockbot backtest KR           # 기법별 과거 성과 확인 (권장)
python -m stockbot run                   # 상시 실행 (스케줄러 + 텔레그램 명령)
```

### 자동 일정 (config.yaml `schedule`)
| 작업 | 한국 | 미국 (뉴욕시간, 서머타임 자동 반영) |
|---|---|---|
| 장중 감시 | 09:05~15:20, 5분 간격 | 09:35~15:55, 5분 간격 (한국시간 밤) |
| 마감 스캔 + 브리핑 | 16:10 | 16:30 (한국시간 새벽 5:30 또는 6:30) |
| 재무데이터 갱신 | 토요일 10:00 (KST) | 〃 |

휴장일(설·추석·한글날, 미국 공휴일 등)은 거래소 달력으로 자동으로 건너뜁니다.

### 텔레그램 명령어
```
/buy 005930 72000 10          매수 등록 (fixed 모드: -5%/+15%)
/buy NVDA 120.5 5 trend       추세 모드 (10일선 이탈 매도 + 불타기)
/buy 000660 180000 5 turtle   터틀 모드 (10일 최저가 이탈 시 전량 매도)
/buy 010140 5200 cycle        사이클 모드 (목표가 알림)
/sell 005930 [가격]            보유 종료
/pos                          보유 종목
/watch KR                     장중 감시 목록
/scan US                      지금 스캔+브리핑
/check KR                     지금 장중 점검
```

### 24시간 돌리기
장중 알림을 받으려면 프로그램이 계속 켜져 있어야 합니다. 방법은 셋 중 하나입니다.
- 항상 켜 두는 PC
- 저렴한 클라우드 서버(1 vCPU / 1GB면 충분)
- 리눅스 서버라면 systemd로 등록:

```ini
# /etc/systemd/system/stockbot.service
[Unit]
Description=stockbot
After=network-online.target
[Service]
WorkingDirectory=/home/<user>/stockbot
ExecStart=/home/<user>/stockbot/.venv/bin/python -m stockbot run
Restart=always
[Install]
WantedBy=multi-user.target
```
`sudo systemctl enable --now stockbot`

## 5. 구조

```
stockbot/
  strategies.py   기법 → 조건식 (스캔과 백테스트가 같은 함수를 사용)
  data.py         종목목록·일봉 수집 + 캐시 (FinanceDataReader, yfinance)
  fundamentals.py 사이클주 재무 (DART, yfinance)
  screener.py     마감 스캔 → 관심종목·감시목록·매수 추천
  monitor.py      장중 매수 타이밍, 보유종목 손절/익절/불타기/10일선
  realtime.py     현재가 (한국투자증권 API / yfinance)
  briefing.py     일일 브리핑
  llm.py          Claude 해설 (선택)
  backtest.py     백테스트
  app.py          스케줄러 · 텔레그램 명령
tests/            가상 데이터로 각 기법 조건 검증 (python -m pytest)
```
